# 密码库（PasswordVault）

一个只给自己用的 iOS 密码管理器。原生 SwiftUI，无第三方依赖，无服务器，无账号。

## 代码本身的设计（这部分是对的，可复用）

**先说结论（三个最容易判断错的地方）：**

- **能实现的**：加密本地存储、Face ID 解锁、密码生成、泄露检测、加密备份。
- **实现不了的**（不管怎么写代码）：**忘记主密码就真的没有救**。
  这是加密的定义，不是偷懒。
- **刻意不做的**：Safari 自动填充。它需要 $99/年开发者账号，
  而你不打算买——所以 v0.2 把它连同相关的复杂度一起删掉了。
  代价是每次登录要「复制 → 切换 → 粘贴」两步。

**一个容易误判的成本**：免费签名 **7 天过期**，但**数据不会丢**。
App 图标变灰点不开，重新签名装回去（别选"卸载"）一切照旧。
用 AltStore + AltServer 可以自动续签，日常基本感知不到。

## 三分钟了解它做了什么

| 能力 | 实现方式 |
|---|---|
| 加密 | AES-256-GCM（CryptoKit），文件头作为 AAD，改一个字节就解不开 |
| 主密码 | PBKDF2-HMAC-SHA256 × 600,000 + 32 字节随机盐（纯系统 API） |
| 日常解锁 | Face ID（`biometryCurrentSet`，换脸即失效） |
| 自动锁定 | 可配（默认切后台 30 秒），锁定时清内存引用 + 清剪贴板 |
| 防截屏泄露 | 场景切换时用不透明遮罩替换内容 |
| 剪贴板 | 写入即带 60 秒系统级过期时间 + `localOnly`（不随 Handoff 同步） |
| 密码生成 | 拒绝采样无取模偏差，20 位 ≈ 130 bit |
| 泄露检测 | HIBP k-匿名：只发 SHA-1 前 5 位，密码不出手机 |
| 备份 | 导出的是**密文本身**，导出流程零解密 |
| 恢复 | 必须先用该备份的主密码解密成功，才允许覆盖现有库 |
| 网络行为 | **只有你主动点"检查泄露"时才联网**。无统计 SDK、不抓图标 |

## 边界与约束（这一节比功能表重要）

**1. 主密码是唯一不可替代的信任根。**
KDF 迭代次数只能把攻击成本乘以 60 万，救不了弱密码。
`password123` 用任何 KDF 都撑不过几秒。**请用 4 个随机单词。**

**2. 没有同步，只有加密备份/恢复。**
CloudKit 级别的记录合并需要付费账号，还要处理冲突、墓碑、时钟偏移——
做错的同步会**静默丢数据**，那比"手动导出"糟得多。

**3. 密码要经过全局剪贴板。**
这是没有自动填充之后的必经之路，也是这个 App 最薄的一环。
缓解措施：60 秒系统级过期（即使 App 被挂起也生效）+ `localOnly`
（不随通用剪贴板跑到你别的设备上）。
另外它有个反直觉的好处：**手动粘贴更免疫钓鱼**——
你不会往一个可疑页面上粘密码。

**4. 不防的事**（详见 `docs/SECURITY.md`）：越狱后的定向分析、
内存取证、键盘记录器、以及**你自己把主密码写在便利贴上**。
最后一条的发生概率远高于其他所有技术攻击。

**5. 这套代码从未被真正的苹果编译器检查过。**
CI 曾在 GitHub Actions 上跑起来，但第 7 步「编译验证」失败，
而 CI 日志需要登录才能读，加上 `github.com` 网页不可达，
始终没能拿到具体错误。所以它**可能只是几个小语法错误**，
也**可能**还有更深的问题——有 Mac 之后第一件事就是编译一遍。

## 快速开始（有 Mac 之后）

```bash
brew install xcodegen
xcodegen generate
open PasswordVault.xcodeproj
```

Xcode 会自动处理免费账号的签名，连上 iPhone 直接跑即可。
`project.yml` 是唯一事实来源，`.xcodeproj` 是生成物，不要手动改。

## 工程约束

- iOS 17.0+，Swift 5.9，Xcode 15.4
- 零第三方依赖（只用 Apple 系统框架）
- **只有一个 target**，`Config/PasswordVault.entitlements` 是空文件（刻意为之）
- `project.yml` 是唯一事实来源，`.xcodeproj` 是生成物，**不入库**
- `Sources/Shared` 里没有一行 SwiftUI 界面代码（只有 `ObservableObject`
  和 `UIPasteboard` 这类非界面依赖），`Sources/App` 里没有一行密码学
- `tools/` 是本地 Windows 辅助脚本，不进 git（见 `.gitignore`）
