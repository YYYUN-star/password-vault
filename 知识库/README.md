## 技术知识速查

从这次项目里提炼出的、**下次能直接用**的条目。
每条都有最小示例，细节在 [`经验教训.md`](经验教训.md) 第二节。

| 主题 | 一句话要点 |
|---|---|
| PowerShell 中文乱码 | PS 5.1 在中文 Windows 上按 GBK 解码无 BOM 的 UTF-8 脚本。**脚本源码只放 ASCII**，中文编码后运行时解码。**注释里也不能有中文** |
| `$ErrorActionPreference='Stop'` | 会把原生命令的 stderr 当致命错误（`ssh -V`、`ssh-keyscan` 成功时也写 stderr）。用统一的 `Invoke-Native` 包装函数 |
| `git config` 的引号 | 会吃掉外层引号。**优先用 8.3 短路径 `C:\PROGRA~1\...` 避开空格**，别跟转义搏斗 |
| GitHub Actions 零任务失败 | 0 秒失败 + `jobs` 为空 = **workflow 文件本身非法**，不是代码问题 |
| workflow 里的 heredoc | XML 必须缩进到块标量内；`<<EOF` 后**必须换行**，否则生成 0 字节文件 |
| 国内网络访问 GitHub | `github.com` 可能不通，但 **`ssh.github.com:443` 通常通**（官方备用通道）。但网页不通 = Actions 结果看不了，"半通比不通更麻烦" |
| Windows 自带 OpenSSH | 9.5 版太老，报 `unsupported KEX method`。**用 Git 自带的**（`C:\Program Files\Git\usr\bin\ssh.exe`，10.x） |
| GitCode 的 runner | 只有 `ubuntu-latest` / `euler-latest`，**没有 macOS** → 编译不了 iOS |
| 浏览器 Web Crypto | 只在 `https://` 或 `localhost` 下可用。`http://192.168.x.x` 不是安全上下文 |
| CI 日志读取 | GitHub API 的日志和 artifact 下载**都需要登录**，匿名拿不到 |

## 密码管理器设计速查

细节在 [`ios密码库-设计要点.md`](ios密码库-设计要点.md)。

| 项 | 决策 |
|---|---|
| 加密 | AES-256-GCM，**文件头作为 AAD**（改一个字节就解密失败） |
| 密钥派生 | PBKDF2-HMAC-SHA256 × 600,000 + 32 字节随机盐 |
| 子密钥分离 | HKDF-SHA256，`info = "vault-content-v1"`，内容密钥 ≠ 主密钥 |
| 区分"密码错"和"文件坏" | 额外存一段 HMAC 校验值（AEAD 不区分这两者） |
| 存储 | 单文件整体加密（不用 SQLite：避免 WAL 明文残留） |
| 随机源 | `SecRandomCopyBytes`，**失败直接崩溃**，绝不退化成伪随机 |
| 密码生成 | 拒绝采样（无取模偏差）；符号集排除 `"` `'` `` ` `` `\` |
| 域名匹配 | **只认精确相等或互为子域**，绝不模糊匹配 |
| 变更检测 | 明文比对，相同则不写盘 |
| 并发 | `@MainActor` 强制串行 |
| 恢复 | 必须先用该备份的主密码解密成功，**才允许写入** |
| 泄露检测 | 只发 SHA-1 前 5 位（k-匿名），三态结果，**失败 ≠ 安全** |
| 不抓 favicon | 会实时暴露"我在用哪些网站" |

## 这份知识库的记录原则

写这几份文档时遵循的规则，供以后参照：

1. **记下"当时为什么这么选"，不只记"选了什么"**
   —— 结论会过时，判断链条不会。

2. **错误要写具体**，包括犯错的次数和当时的心理
   —— "我打到第 5 个补丁才回头"比"要注意及时止损"有用得多。

3. **区分"我做不到"和"环境不支持"**
   —— 这次是后者（没有 Mac），不是前者（不会写）。

4. **可复用的技术要点带最小示例**
   —— 描述再准确，也不如一段能直接抄的代码。

5. **失败的项目也要保存"做对的部分"**
   —— 加密方案、威胁模型、测试习惯这些和平台无关，下次还能用。
